# ♿ AccessAble LK

**AccessAble LK** is a real-world accessibility-focused web application designed to help people discover and understand the accessibility facilities available at public and private places.

The platform is designed for wheelchair users, people with disabilities, elderly people, people with temporary mobility difficulties, and anyone who needs accessibility-related information before visiting a place.

## 🎯 Project Overview

Many people cannot easily find reliable information about accessibility facilities before visiting places such as hospitals, banks, restaurants, hotels, public offices, universities, shopping malls, and other public locations.

AccessAble LK provides a centralized platform where users can:

* Search for accessible places.
* Filter places based on accessibility requirements.
* View detailed accessibility information.
* View accessibility scores.
* View location information.
* Read user reviews.
* Save favorite places.
* Report accessibility problems.
* Track reported issues.
* Receive notifications.

Organizations can manage their places and submit accessibility information for verification, while administrators and authorized officers can manage and verify the information provided by users and organizations.

## 🛠️ Technologies Used

* **PHP**
* **MySQL / MariaDB**
* **Apache**
* **XAMPP**
* **PHP Sessions**
* **PDO / Prepared Statements**

The application is developed as a **server-rendered PHP web application** and does not use Laravel or a separate frontend framework.

## 🏗️ System Architecture

The application follows a PHP-based web architecture:

```text
User
  ↓
PHP Web Application
  ↓
Application Logic
  ↓
MySQL Database
```

## 🌍 Real-World Problem

People with disabilities and mobility limitations may not have enough reliable information about accessibility facilities before visiting a place.

AccessAble LK addresses this problem by creating a centralized platform where accessibility information can be discovered, reviewed, verified, and continuously updated.
